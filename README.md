# 営業バックオフィス｜AI引継ぎガイド

受注後の **契約書対応・請求書発行・入金確認** を、自分のAIに相談しながら進めるための説明書です。

OTの説明と録画をもとに整理した **実務開始前の準備版** です。実際の作業で確認できた内容を、今後追加していきます。

## 使い方

URLを読み取れるAIに、次のメッセージを送ってください。

> このリポジトリの **AI_GUIDE.md** を読んで、説明書に沿って作業を手伝ってください。今回は〇〇社の案件です。何から始めればいいか、必要な情報から一緒に確認してください。

途中からなら「契約書はできたので、クラウドサインで送るところから進めたいです」など、今の状況を添えてください。

**[AI向け説明書を開く](AI_GUIDE.md)**

AIがリポジトリ内のファイルを開けない場合は、上の説明書のリンクを渡してください。それでも読めない場合は本文をコピーして渡せます。リンクを受け取っただけで、画面操作や送信が自動実行される仕組みではありません。

## 内容

- 契約書の作成・送付・締結確認
- 研修案件の追加書類
- 請求書の入力・確認・PDF作成
- 入金確認・未入金フォロー・営業への完了報告
- 未確認事項と、実務で分かったことの追記方法

公開するのは説明書のみです。業務システムのアクセス先や顧客・案件の情報は、社内の方法で確認してください。
